# ☕ Estudos de Java

Bem-vindo ao meu repositório de estudos em **Java**! 🚀

Este repositório foi criado para registrar minha jornada de aprendizado na linguagem Java, reunindo exercícios, exemplos, desafios e pequenos projetos desenvolvidos ao longo dos meus estudos.

Além de acompanhar minha própria evolução, deixo este material disponível para **outras pessoas que estejam começando a estudar Java ou iniciando sua carreira na área de desenvolvimento**.

## 📚 Conteúdo

Aqui você encontrará conteúdos relacionados a:

* Fundamentos da linguagem Java
* Variáveis e tipos de dados
* Estruturas condicionais
* Estruturas de repetição
* Arrays e Collections
* Métodos e funções
* Programação Orientada a Objetos (POO)
* Encapsulamento, herança e polimorfismo
* Tratamento de exceções
* Manipulação de arquivos
* Streams e Lambda
* Exercícios e desafios
* Projetos práticos

> O conteúdo será atualizado conforme eu avanço nos estudos.

## 🎯 Objetivo

Meu objetivo é aprender Java de forma **progressiva e prática**, colocando em código os conceitos estudados e construindo uma base sólida para minha carreira como desenvolvedor.

Este repositório também pode servir como material de consulta para quem estiver passando pelo mesmo processo de aprendizado.

## 🗂️ Organização

Os conteúdos são organizados de acordo com os assuntos estudados, facilitando a navegação e permitindo acompanhar a evolução dos conceitos mais básicos até assuntos mais avançados.

## 🤝 Contribuições

Este é um repositório pessoal de estudos, mas fique à vontade para explorar o conteúdo, utilizar os exemplos como referência e compartilhar sugestões ou melhorias.

Se você também está começando na programação, espero que este repositório possa ajudar na sua jornada! ☕💻
